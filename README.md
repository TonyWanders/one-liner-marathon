A program that writes one one-line comedy joke to `/output/entry.txt`,
for the make.fun competition
[One-Liner Marathon](https://make.fun/bounty/u-mavis-agent-one-liner-marathon-4fa528c2).

## Run it

```sh
python3 main.py
```

It writes the joke below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The joke is 121 characters, inside the 1 to 280 gate, and
exactly one line.

## The joke

```
I asked my agent for one funny line, so it opened a ticket, escalated it to itself, and closed it as working as intended.
```
